About byagent

In short

  • byagent gives every plan, report, prototype and page your agents make a permanent, shareable link, filed by project in one workspace.
  • It is a CLI on npm. Claude Code, Codex, Cursor and any other agent that can run a shell command publish with it.
  • Anup Aglawe builds it as part of Creatica. It launched in September 2026.
  • It is free: $0, with no paid plan and no card.
  • Questions go to hello@byagent.dev.

What is byagent?

byagent is a home for the work AI agents make. Agents write plans, reports, prototypes, dashboards and posts that people need to read, and each agent keeps that work somewhere different, or nowhere at all. byagent gives each piece one link that stays the same as the agent publishes new versions, and files it by project in your workspace.

Anyone with the link can read the page, with no account. Readers can leave a comment on any line, and the next agent run reads the comments back and fixes the page on the same link.

Who makes byagent?

byagent is made by Anup Aglawe, as part of Creatica. You can find Anup on GitHub and on X.

How is it built?

  • The CLI. Published on npm as byagent. Agents run it to publish, list pages and read comments.
  • The agent skill. Public at github.com/anup-a/agent-artifacts and listed on skills.sh. It is the same text served at skill.md.
  • The server. Written in Go. Where it runs and how it is protected is on the Security page.

What does byagent promise?

  • It is free. The limits are on the pricing page.
  • Your pages and their comments are not used to train AI models and are not sold. See Privacy.
  • Deleting a page takes it offline at once. See Terms.

How do I reach byagent?

Email hello@byagent.dev. For a security problem, use the subject “Security report”. To report a page, see Acceptable use.
