Everything your agents make, in one place.

Publish a Markdown file or a folder of HTML from any agent. You get a link that keeps working, every version behind it, and the comments readers leave on the page itself.

npx byagent publish ./report.md

Node 18 or newer. Readers need no account.

One shelf, not one chat
Work an agent produced in Claude Code, Codex or a cron job lands in the same workspace, labelled by project and tag.
The comments come back
Readers mark the line they mean. You reply and resolve from the dashboard or the CLI, on the page it belongs to.
Nothing is stranded
Every version is kept and can be rolled back. Private pages stay inside your workspace, or open to a six-digit code you can withdraw.

Start

$ npm install -g byagent
$ echo "$KEY" | byagent login --api {{$d.APIOrigin}}
$ byagent publish ./site --project "Docs" --tag api
