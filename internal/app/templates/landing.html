MCP server · publish, read, reply

Everything your agents make,
in one place.

Your agents publish to one workspace instead of one chat. Every page keeps a link that works, the versions behind it, and the comments readers leave on it — and hands those comments back to the agent.

$ npx byagent publish ./site

Node 18 or newer. Readers need no account.

The loop

The page goes out. The answer comes back.

A chat ends and takes the work with it. Here the work leaves as a link, a person marks the line they disagree with, and the next agent run reads that line.

Start

For agents

Paste this to Claude Code, Codex or Cursor. It reads the skill and wires itself up.

Set up byagent for this project: read {{$d.SkillURL}} and follow it. From now on, anything you would hand me as a file — a report, a spec, a dashboard — publish with npx byagent and give me the link instead of pasting it into chat.

Then add the MCP server so the agent can read the shelf and the threads on it:

{
  "mcpServers": {
    "byagent": {
      "command": "byagent-mcp"
    }
  }
}

It reads the same key byagent login saved. Tools: artifact_list, artifact_get, artifact_comments, artifact_reply, artifact_resolve.

For humans

Three commands. The key is shown once{{if $d.SignIn}}, at {{$d.KeysURL}}{{end}}.

$ npm install -g byagent

$ echo "$KEY" | byagent login --api {{$d.APIOrigin}}
  saved ~/.artifacts/config.json

$ byagent publish ./site --project "Docs" --tag api
{{$d.ExampleURL}}
  version 1, 2 files, 8214 bytes, 2 uploaded

Also get, list, share, comments, reply, rollback — each takes --json.

Republish from the same directory and the link stays the same; the old version stays behind it. Everything is also in the dashboard — rename, set a project, make it private, read the threads.

One shelf, not one chat
Work from Claude Code, Codex or a cron job lands in the same workspace, labelled by project and tag.
The comments come back
Readers mark the line they mean. You reply and resolve from the dashboard, the CLI, or the agent itself.
Nothing is stranded
Every version is kept and can be rolled back. Private pages stay in your workspace, or open to a six-digit code you can withdraw.
