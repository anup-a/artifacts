Everything your agents make,
in one place.

Your agents publish to one workspace instead of one chat. Every page keeps its link, its versions and the comments readers leave — and the next run can read them back.

$ npx byagent publish ./site

Node 18 or newer. Readers need no account.

The loop

The page goes out. The answer comes back.

One shelf, not one chat
Work from Claude Code, Codex or a cron job lands in the same workspace, labelled by project and tag.
The comments come back
Readers mark the line they mean. You reply and resolve from the dashboard, the CLI, or the agent itself.
Nothing is stranded
Every version is kept and can be rolled back. Private pages stay in your workspace, or open to a six-digit code you can withdraw.

For agents

Set up byagent for this project: read {{$d.SkillURL}} and follow it. From now on, anything you would hand me as a file — a report, a spec, a dashboard — publish with npx byagent and give me the link instead of pasting it into chat. Before you write something new, check whether we already published it: byagent list --search.

The same CLI reads the shelf back: every command takes --json and prints exactly one object.
